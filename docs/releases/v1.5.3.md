Dino Player 1.5.3 fixes export scaling for non-16:9 videos, smooths out several rough edges, and reduces background work while you review footage.

## Changes

- Exporting at 720p, 1080p, 1440p or 2160p (4K) now keeps the video's shape. A 21:9 or 4:3 recording at 1080p comes out at 2580x1080 or 1440x1080 with square pixels, instead of a stretched 1920x1080.
- The export folder follows each video you open until you choose one with Browse. Changing the default location in Preferences takes effect right away.
- Turning Crop off and on keeps your selection. Turning it on near the end selects the last ten seconds.
- Escape closes Preferences and the preset name dialog. The speed shortcut fields no longer capture Tab, Enter or Escape.
- Clear messages when FFmpeg is missing or cannot run, or when a video takes too long to prepare.
- Only the newest 20 diagnostic logs are kept.
- Less background work: the hidden diagnostic log and export queue no longer refresh constantly, and logging no longer writes to disk from the playback thread.

See the [changelog](../../CHANGELOG.md) for the full list.

## Downloads

Download the ZIP for your platform, extract the whole archive to a writable folder, and run `Dino Player.exe` on Windows or `./"Dino Player"` on Linux. No separate .NET, mpv, or FFmpeg installation is needed. Keep the included `settings.json` beside the app.

- Windows x64: Windows 10/11.
- Linux x64: glibc 2.35+, X11/XWayland, system graphics/audio/font libraries and GPU drivers. Run `bash install-desktop.sh` for an optional applications-menu launcher. Restore executable bits if necessary with `chmod +x "Dino Player" ffmpeg install-desktop.sh`.
- Check downloads against `Dino-Player-v1.5.3.sha256`.

The bundled mpv, FFmpeg and native libraries are the same as in 1.5.2.

## Validation

Release builds pass the non-graphical, FFmpeg/libmpv integration, seek and interactive UI suites on Linux.

Interactive Windows playback has not yet been validated. Real NVIDIA NVENC encoding is not covered by these checks.
