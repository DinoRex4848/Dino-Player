Dino Player’s first GitHub release includes refreshed portable builds for Windows and Linux x64.

## Changes

- More responsive skipping with keyboard arrows, held keys, and skip buttons.
- Prompt timeline updates in windowed and fullscreen playback.
- Videos begin at zero after initial frame preparation and audio setup.
- The import prompt stays visible while browsing for a video and after cancelling.

## Downloads

Download the ZIP for your platform, extract the whole archive to a writable folder, and run `Dino Player.exe` on Windows or `./"Dino Player"` on Linux. No separate .NET, mpv, or FFmpeg installation is needed. Keep the included `settings.json` beside the app.

- Windows x64: Windows 10/11.
- Linux x64: glibc 2.35+, X11/XWayland, system graphics/audio/font libraries and GPU drivers. Run `bash install-desktop.sh` for an optional applications-menu launcher. Restore executable bits if necessary with `chmod +x "Dino Player" ffmpeg install-desktop.sh`.
- Check downloads against `Dino Player V1.5.2.sha256`.

## Validation

Release builds and the non-graphical regression suite run on Windows and Linux in GitHub Actions. Linux also receives FFmpeg/libmpv integration and local interactive UI checks, including rapid seeks, both timelines, zero-second imports, and import-picker visibility/cancellation.

Interactive Windows playback has not yet been validated. Real NVIDIA NVENC encoding is not covered by the hosted checks.

Dino Player is GPL-3.0. Each ZIP contains `LICENSE.txt` and third-party component notices in `README.txt`. Source, build instructions, dependency provenance, and the full user guide are included in the repository.
