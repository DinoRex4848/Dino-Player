Dino Player 1.6.0 makes clipping faster and more precise, adds exports that fit under an upload limit, and makes the player feel snappier. Track volumes and checkboxes now change live without pausing playback. This release also includes the 1.5.3 fixes, which were not published separately.

## New

- **Target size export**: choose Target size on the Export tab and enter a size in MB, such as a chat app's upload limit. Dino Player works out the bitrate from the clip length and audio, and encodes again at a lower bitrate if the file still comes out too big.
- **Export clip** below the timeline (also **Ctrl+E**) exports the current crop with the Export tab's settings without leaving the player.
- **Show in folder** in the export queue opens the finished clip's folder, ready to drag into a chat.
- **New keys**: **,** and **.** step one frame, **Shift+Left/Right** moves exactly one second, **I** / **O** set the crop start and end, **Up/Down** change volume and **M** mutes.
- **Drag to scrub** along the timeline, the fullscreen timeline or a crop handle. Crop handles show the frame you are cutting at.
- **Open with Dino Player**: videos opened from a file manager or passed on the command line load at startup. On Linux, run `install-desktop.sh` again to add Dino Player to Open With.

## Faster and smoother

- Changing a track's volume or turning a track on or off no longer pauses playback.
- Opening a video is faster, and the play/pause button and speed update instantly.
- The playhead moves smoothly while playing, and Set Start, Set End, I and O use the exact frame on screen.
- The portable builds start about 2.5× faster. The ZIPs are about 20 MB larger because the app is precompiled and no longer compressed.
- NVENC exports also decode on the GPU, using about a third of the CPU time.

## Included from 1.5.3

- Exporting at 720p, 1080p, 1440p or 2160p keeps the video's shape instead of stretching 21:9 and 4:3 recordings.
- The export folder follows each video you open until you choose one with Browse.
- Turning Crop off and on keeps your selection; Escape closes Preferences and the preset name dialog.
- Clearer messages when FFmpeg is missing or a video takes too long to prepare; only the newest 20 diagnostic logs are kept.

## Downloads

Download the ZIP for your platform, extract the whole archive to a writable folder, and run `Dino Player.exe` on Windows or `./"Dino Player"` on Linux. No separate .NET, mpv, or FFmpeg installation is needed. Keep the included `settings.json` beside the app.

- Windows x64: Windows 10/11.
- Linux x64: glibc 2.35+, X11/XWayland, system graphics/audio/font libraries and GPU drivers. Run `bash install-desktop.sh` for an optional applications-menu launcher. Restore executable bits if necessary with `chmod +x "Dino Player" ffmpeg install-desktop.sh`.
- Check downloads against `Dino-Player-v1.6.0.sha256`.

The bundled mpv, FFmpeg and native libraries are the same as in 1.5.2.

## Validation

Release builds pass the non-graphical, FFmpeg/libmpv integration, seek and interactive UI suites on Linux, including real NVIDIA NVENC exports. The Windows build passes the non-graphical suite in GitHub Actions.

Interactive Windows playback has not yet been validated.
